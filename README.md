# helios-paper

Code and manuscript for "Modelling the public-health impact of indoor air quality interventions on respiratory virus transmission" ([medRxiv](https://www.medrxiv.org/content/10.64898/2026.06.06.26355067v1)) based on the [`helios`](https://github.com/mrc-ide/helios) R package.

## File structure

- `R/`: Reusable functions
- `figures/`: Scripts to set-up, run, analyse, and produce figures
- `manuscript/`: Quarto files for the manuscript and supplementary information
- `tables/`: Tables to be included in the manuscript
- `tests/`: Lightweight tests for functions
